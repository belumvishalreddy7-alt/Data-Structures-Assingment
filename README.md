This project contains some basic Data Structures programs written in C. These programs mainly use stack and queue concepts to solve different problems.

Programs Included

Q1. string reversal using stack This program takes a string as input and reverses it using a stack.

Q2. balanced expression check This program checks whether the given expression has balanced brackets like (), {}, [].

Q3. next greater element This program finds the next greater element for each element in an array.

Q4. printer queue This program simulates a printer queue where documents are added and printed in order.

Q5. circular queue This program implements a circular queue with operations like insert, delete, display, and peek.
